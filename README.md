# LevelUp IELTS Platform

Nền tảng biến mục tiêu IELTS 7.5 thành hành trình nhiệm vụ hằng ngày, có website người dùng, admin control panel, gamification, Telegram notifications và nền móng thương mại.

> Biến mục tiêu đời thật thành nhiệm vụ mỗi ngày.

## Trạng thái

Repository đang được triển khai theo từng phase có kiểm thử và tài liệu kiến trúc rõ ràng.
